PDF Toolbox – Política de Privacidade

Última atualização: 7 de novembro de 2026

Português

A extensão PDF Toolbox não coleta, não armazena em servidores, não vende e não compartilha nenhum dado pessoal ou de navegação.

  • Processamento 100% local: editar, converter, dividir, juntar e capturar páginas acontece dentro do seu navegador. Nenhum arquivo ou conteúdo de página é enviado para servidores, seja nosso ou de terceiros.
  • Sem analytics, sem rastreamento, sem anúncios. A extensão não faz chamadas para serviços externos.
  • Detecção de documentos: a extensão lê os cabeçalhos das respostas de rede (tipo de conteúdo e nome do arquivo) e os links das páginas apenas para identificar PDFs e documentos Word. Essa lista fica em chrome.storage.session, na memória do navegador, e é apagada quando você muda de página ou fecha o navegador.
  • Download de anexos: quando você pede para abrir um documento (por exemplo, um anexo do Gmail), a extensão o baixa usando a sua própria sessão no site, como se você clicasse em "baixar". O arquivo é aberto só no seu navegador.
  • Preferências: a única configuração salva (formato da cópia: PNG ou PDF) fica em chrome.storage.local, no seu computador.
  • Todo o código é aberto: github.com/guianayans/pdfToolbox.

O uso de informações recebidas das APIs do Chrome segue a Política de Uso Limitado do Programa de Desenvolvedores da Chrome Web Store.

English

PDF Toolbox does not collect, transmit, sell or share any personal or browsing data.

  • All processing is local: editing, converting, splitting, merging and capturing pages happens entirely in your browser. No file or page content is ever sent to any server.
  • No analytics, no tracking, no ads. The extension makes no calls to external services.
  • Document detection: the extension reads network response headers (content type and file name) and page links only to identify PDF and Word documents. This list is kept in chrome.storage.session (browser memory) and is cleared when you navigate away or close the browser.
  • Attachment download: when you choose to open a document (e.g. a Gmail attachment), it is fetched with your own existing session, exactly as if you clicked "download", and opened only in your browser.
  • Preferences: the only saved setting (copy format: PNG or PDF) is stored locally in chrome.storage.local.
  • The source code is open: github.com/guianayans/pdfToolbox.

The use of information received from Chrome APIs adheres to the Chrome Web Store Limited Use requirements.
